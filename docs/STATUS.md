## 已知边界

- 正式赛事模型、沙盒与计分尚未联调；本地模拟回复不能证明新 prompt 提高准确率或胜率。
- 候选匹配是来源检查，不是答案语义认证。任意任务的 schema 自动抽取、字段正确性判断、认证过的技能库没有实现。
- 无候选、未知截止时间、未观测空窗的同描述换题仍可能无法可靠保底；不会虚构答案或任务 ID。
- 36,000 是辅助上下文字符预算，不是模型 token 窗口。长输出可能裁去中间信息，完整任务本身也可能超出未知的模型窗口。
- 本地原文审计默认关闭；只有获准保存在私有目录时开启。文件写入故障隔离不是硬实时保证。
- 默认 defense 仍未接入新闻/寻宝执行。此前夜战、生存、资本交付、动态弹道等实机不确定性仍保留。
